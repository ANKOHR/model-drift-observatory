# Lessons for KOML

Exact paired observations make deterministic comparisons easy to audit, but a response text difference does not establish meaningful model degradation. Probe matching and a chosen latency threshold define what the result means.

The planted fixture validates the narrow assumption that the four specified comparison rules find every planted change without flagging controls. A corrupted status observation reduces the changed count from 80 to 79, demonstrating computation from data rather than a static summary. Production usefulness and accuracy remain unmeasured.

Operating rule: define the observation contract and independent expected IDs before implementing a detector, preserve provenance and source hashes, and require hand-checked real samples before making broader claims.
